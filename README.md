# 启思 AI 家教 · QiSi AI Tutor

> 一个**不直接给答案、苏格拉底式引导**的 K12（初中数学）AI 家教 MVP 原型。
> 拍题 → 分步引导 → 分层提示 → 独立做出 → 数据沉淀 → 家长学情周报。

依据自写的《启思 AI 家教 · 产品需求文档 PRD v1.0》实现。**不是写死的点击 Demo**——对话状态机、答案等价判定、掌握度、错题本、家长周报全部是实时算出来的，数据存浏览器本地（刷新不丢）。纯前端、零构建、双击即跑。

🔗 **在线体验**：`https://zhangxiaoteng86.github.io/qisi-ai-tutor/`（推送 + 开启 Pages 后即可访问）

---

## ✨ 亮点（这个项目想证明什么）

- **真·苏格拉底引导引擎**：会话级状态机（`stepIndex / hintLevel / wrongStreak / status`），每轮按硬规则决策"追问 / 判正推进 / 不给答案地纠错 / 升档提示 / 终局复盘"。
- **两套可切换内核**：默认**规则脚本引擎**（离线、稳定、防泄题 100% 可控）；可一键切到 **AI 模式（Claude）**，BYOK 直连大模型引导任意题。
- **防泄题安全层（PRD 7.3）**：模型每条回复在下发前过一道"后置校验"——若在学生未求助到第④档时疑似包含最终答案，则拦截、降级为安全话术并记 `leak_blocked`。可观测、可验证。
- **RAG 知识接地（PRD 7.1）**：内置课标对齐知识库（公式/定理/方法/易错点）+ 稀疏检索器；引导前先检索相关知识，拍题确认页**可视化检索结果**，AI 模式下注入模型上下文保证内容正确、与课内对齐。检索打分可平滑升级为向量嵌入。
- **数据驱动闭环**：一切结论从埋点事件聚合——掌握度三档滚动计算、错题本自动归集、家长周报真实生成（数据不足出友好版）。
- **答案等价判定**：`x=4` ≡ `4`、`4 米` ≡ `4`、全角 `＝`、`x²` ≡ `x^2`、数值等价归一。

## 🚀 运行

**方式一（推荐）**：双击 `index.html`，浏览器打开即玩。

**方式二**：本地静态服务（规避个别浏览器对 `file://` 的限制）
```bash
node server.js     # → http://localhost:5173
```

打开后默认「学生端」。首页点 **📷 拍题求助** → 选一道示例题 → 确认题干 → 进入引导对话。
顶部可切「家长端」生成学情周报；「我的 → 埋点事件流」看全链路事件。

## 🤖 AI 模式（BYOK，可选）

默认走规则脚本，**无需任何 Key**。想体验真实大模型引导：

1. 「我的 → 🤖 AI 内核」→ 选 **AI 模式（Claude）**；
2. 填入你自己的 **Anthropic API Key**（默认模型 `claude-sonnet-4-6`，可改）；
3. 保存后，下一道题的引导对话即由 Claude 驱动；引擎仍会对模型每条回复过防泄题校验。

> 🔒 **安全**：Key 只存浏览器 `localStorage`，**不上传、不进 Git 仓库**。浏览器直连 Anthropic 用了 `anthropic-dangerous-direct-browser-access` 头，Key 在前端可见——**仅适合本地体验 / Demo**。生产环境请把 `assets/llm-adapter.js` 里的 `callClaude` 改为指向你的**后端代理**（Key 放服务端环境变量）。

| 错题/掌握度 | 6.3 | 独立做出不入本；用高档提示/未独立做出自动归集；掌握度三档滚动计算 |
| 智能复习 | 3.1 / 6.3.3 | 遗忘曲线调度（SM-2 简化版）：到期知识点进「今日待复习」，点开服务**同类变式题**；含「模拟过一天」演示控件 |
| RAG 知识接地 | 7.1 | 课标知识库（公式/定理/方法/易错点）+ 稀疏检索；确认页可视化检索结果，AI 模式注入提示词；`rag_retrieve` 埋点 |
| 家长周报 | 6.4 | 按本周真实埋点聚合；数据不足出友好版；建议正向、无排名/贬低 |
| 埋点 | 第 9 章 | 全链路事件，「我的 → 埋点事件流」可视 |

## 🏗️ 架构

事实来源是**埋点事件流**，所有派生数据从中聚合（对齐 PRD 第 9 章）：

```
              ┌─────────────┐
 学生作答 ───▶ │  engine.js  │  状态机 + 判定 + 提示阶梯 + 防泄题后置校验
              └──────┬──────┘
       规则脚本 ◀────┤────▶ AI 模式（llm-adapter.js → Claude，BYOK）
                     │  每轮产出 → track(event)
              ┌──────▼──────┐
              │  store.js   │  events[] ──聚合──▶ 掌握度 / 错题本 / 家长周报 / 首页指标
              └──────┬──────┘   （localStorage 持久化）
              ┌──────▼──────┐
              │   app.js    │  导航 / 模拟拍题 / 对话渲染 / 图谱 / 周报 / 埋点面板
              └─────────────┘
```

```
index.html            页面骨架（手机壳、Tab、引导对话覆盖层、设置抽屉）
assets/app.css        样式（蓝色主题）
assets/data.js        题库 + 知识点体系（14 道题 / 覆盖 7 个知识点 / 每点 2 道，每步含 4 档提示）
assets/kb.js          课标知识库（公式/定理/方法/易错点 21 条）+ 稀疏检索器（RAG）
assets/store.js       数据/埋点层：事件流 → 掌握度/错题本/周报 全由此聚合，localStorage 持久化
assets/engine.js      苏格拉底引导引擎：状态机 + 等价判定 + 提示阶梯 + 防泄题后置校验；脚本/LLM 双内核
assets/llm-adapter.js AI 模式适配器（BYOK 浏览器直连 Claude）；默认不启用
assets/app.js         UI 控制层
server.js             预览用极简静态服务器（零依赖）
```

## 🛠️ 技术

纯原生 **HTML / CSS / JavaScript**，无框架、无构建步骤、无第三方运行时依赖。
状态管理与数据聚合手写；引擎同步（脚本）与异步（LLM）统一用 `Promise.resolve` 调度，互不影响。
